# Product API
This API was built as part of spring boot course. In this chapter, it was created an REST API for products, including all method: GET, POST, PUT and DELETE.

** This project doesn't use Service layer, all the bussiness logic is in the Controller.

#### This project:

Controller < Repository < Model

#### The correct methodology

Controller < Service < Repository < Model 

** DTO, and Mappers


### In this chapter we built:

UPDATE - Create a product.

GET - Get a product by ID.

GET - Get products by name.

UPDATE - Update a product.

DELETE - Delete a product.
